# TROÇKİ Motion Studio

Görsellerden sinematik videolar üreten masaüstü video stüdyosu.

- **Teknoloji:** C# · Windows Forms · FFmpeg
- **Özellikler:** Çoklu görsel seçimi, zoom/pan hareketleri, fade geçişleri, 16:9 / 9:16 / 1:1 oranları, 24/30/60 FPS, tek MP4 çıktısı
- **Yol haritası:** Güvenli fit + pan, gerçek crossfade, görsel bazlı süre/hareket, ses ve proje kaydetme, AI video
